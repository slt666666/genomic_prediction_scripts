# Scripts for Genomic Prediction uinsg NAM population.

These .ipynb files contains all scripts used in the paper (Sakai et al., 2025)

* PART0_NAM_stats ... Scripts to calculate NAM statistics
* PART1_make_Haplotype_block ... Scripts to make genotype data of haplotype block (HB)
* PART2_phenotype_stats ... Scripts to visualize phenotypic variations in NAM population
* PART3_Model_comparison ... Scripts to compare statistical models for genomic prediction
* PART3_Sup_other_crops ... Scripts to apply genomic prediction model to other crops
* PART4_Small_number_HBs ... Scripts to compare prediction accuracies agains the number of HBs
* PART5_Build_application_model ... Scripts to decide the model to apply breeging strategy
* PART6_Validate_with_breeding_lines ... Scripts to validate constructed prediction models
* PART7_Select_useful_RILs ... Scripts to select optimal RILs to provide cross breeding
* PART8_Breeding_plan ... Scripts to simulate cross breeding using selected RILs
* PART8_Sup_Simulate_recombination ... Scripts to simulate recombination events
* PART9_F2_Prediction ... Scripts to predict F2genotypes for validation of our genomic breeding strategy
* modules ... functions to implement scripts
